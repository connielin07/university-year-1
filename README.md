# Year 1 Portfolio – YITING LIN @ Fu Jen Catholic University, Medical Informatics

This repository documents my learning outcomes and hands-on projects during my first year of university. It includes coursework reports, self-directed projects, and exploratory learning experiences, through which I gradually built a foundation in programming and cybersecurity.

---

## Featured Projects

These two projects represent the hands-on work in which I invested the most time and logical design thinking during my first year.

### [JSP Form Upload System](reports/程式設計(二)_JSP表單上傳系統.pdf)

A medical data upload platform built with Java Servlet and MySQL, supporting form data processing, database storage, and success page feedback.

- Technologies: Java, JSP, Servlet, MySQL
- Features: Form input → Data validation → Database insertion
- Key learning points: MVC structure design, data transmission, exception handling

---

### [Course Review Query System](reports/資安導論_查詢課程評價系統.pdf)

An automated course review query system that integrates Python and API techniques to search for course recommendation discussions on Classin.

- Technologies: Python, Selenium, OpenAPI, Dify, web data parsing
- Features: Keyword input → Multi-platform crawling → Integrated course review recommendations
- Key learning points: Browser automation, API calls, and data cleaning
